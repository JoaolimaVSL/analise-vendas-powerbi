Sobre o projeto
Este projeto foi desenvolvido no Microsoft Power BI com o objetivo de apresentar informações relacionadas à gestão de vendas por meio de um relatório interativo e visual. O dashboard busca facilitar a análise dos dados comerciais, permitindo uma melhor compreensão do desempenho das vendas e apoiando a tomada de decisões baseada em dados.

Objetivos
Organizar e visualizar informações de vendas.
Facilitar a interpretação dos dados por meio de gráficos e indicadores visuais.
Apoiar o acompanhamento do desempenho comercial.
Transformar dados em informações úteis para a tomada de decisões.
Aplicar conhecimentos de Business Intelligence (BI) e análise de dados.

Ferramentas utilizadas
Microsoft Power BI Desktop — criação e visualização do relatório.
Power Query — ferramenta para preparação e transformação de dados, quando aplicável.
Modelagem de dados — organização dos dados para análise.
Visualização de dados — apresentação das informações em gráficos e indicadores.

Explore as páginas, os gráficos e os filtros disponíveis no relatório.
